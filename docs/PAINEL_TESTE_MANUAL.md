# Painel — roteiro de teste manual

Para conferir com login real depois de ligar as flags no `backend/.env` (lista em
[ATIVACAO_RECURSOS.md](ATIVACAO_RECURSOS.md)) e reiniciar o `INICIAR.cmd`.

"Automático" quer dizer: testado no navegador com API simulada (`frontend/tests/dashboard-home-check.cjs`
e `browser-check.cjs`) e, para as funções do banco, no teste integrado de 20/11/2026. Nada disso
substitui o teste com a sua conta: a coluna **Você** é para marcar.

Gerar cartões com IA tem custo de provedor: teste uma vez, com 5 cartões.
